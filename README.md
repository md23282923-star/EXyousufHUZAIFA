## 🌐 Deploy to GitHub Pages
1. Create a repository named `exyousufhuzaifa.github.io` on GitHub.
2. Push this folder to `main`.
3. Enable GitHub Pages in repository settings: **Settings > Pages > Branch: main**.
4. Submit `sitemap.xml` to [Google Search Console](https://search.google.com/search-console).
